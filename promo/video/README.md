**Файл:** [`promo-ru.mp4`](promo-ru.mp4) — горизонтальное видео для черновика игры.

| Параметр | Значение | Требование Консоли |
|---|---|---|
| Кадр | 1920×1080, 16:9, 30 fps | 16:9, высота от 400 px ✅ |
| Длительность | 26,3 с | до 28 с ✅ |
| Размер | 18,5 МБ | до 100 МБ ✅ |
| Формат | MP4: H.264 High (yuv420p, BT.709) + AAC 48 кГц стерео, faststart | MP4 ✅ |

## Что в ролике

Реальная игра из текущей сборки (`dist/`, русская версия), без монтажа интерфейса.
Поверх игры добавлены только курсор, круги от кликов, подписи и финальная карточка.

| Время | Что происходит | Подпись |
|---|---|---|
| 0–9,4 с | Клики по BMW Z4 с критами, баланс растёт, кнопка «Выкупить» → окно «Новая тачка в гараже» (BMW i8, конфетти) → клики по i8 | «Кликай и зарабатывай», «Выкупай легендарные модели» |
| 9,4–13,1 с | Вкладка «Прокачка»: шесть покупок подряд («Мойка до блеска», «Химчистка салона») | «Прокачивай свой автобизнес» |
| 13,1–19,7 с | Вкладка «Удача»: контейнер из Тольятти, лента → остановка на легендарной карте BMW M1 → экран «Новая карта коллекции!» | «Выбивай редкие карты» |
| 19,7–22,5 с | Нарезка эпох: Dixi 1928 → BMW 507 → BMW i3 Neue Klasse (коллекция собрана) | «23 модели · от 1928 до наших дней» |
| 22,5–26,3 с | Финальная карточка: «ПЕРЕКУП BMW», «Собери всю историю — от Dixi 1928 до Neue Klasse», кнопка «Играй сейчас» | — |

**Звук.** Игровые звуки пересинтезированы по настоящим вызовам WebAudio из игры, синхронно с кадром.
Музыка — оригинальная подложка 128 BPM, целиком синтезирована скриптом `tools/audio.py`, поэтому
сторонних лицензий нет. Смены сцен попадают в долю, остановка ленты контейнера совпадает с «дропом».
Громкость: пик −1 dBFS, RMS ≈ −16,7 dBFS. Подписи дублируют смысл, так что ролик понятен и без звука.

**Честность геймплея.** Разные этапы игры показаны через заранее подготовленные сохранения
(поздняя игра, начало, середина). Криты и выпадение легендарной карты зафиксированы через
очередь значений `Math.random` — это выпадения, которые игрок реально может получить. Логика и
интерфейс игры не менялись.

> ⚠️ Как и в самой игре, в кадре видны эмблемы BMW на машинах и логотип в шапке — это тот же
> риск п. 3.5 (авторские права), что описан в `CHECKUP.md`.

## Куда загружать

Консоль разработчика → черновик игры → поле **«Горизонтальное видео»** → `promo/video/promo-ru.mp4`.

## Как пересобрать ролик (`tools/`)

Покадровая запись в headless Chromium с виртуальным временем: таймеры, rAF, `Date`/`performance.now`
и CSS-анимации шагают строго на 1/30 с, поэтому запись детерминирована и повторяется до пикселя.

Нужно: Node 20+, Chrome/Chromium 120+ (путь — в переменной `CHROME`), Python 3.10+ с
`numpy scipy pillow` (`tools/requirements.txt`), `ffmpeg` с libx264 (путь — в `FFMPEG` или в `PATH`).

```bash
npm run build:yandex                    # свежая сборка dist/index.html (в корне репозитория)
cd promo/video/tools
npm install                             # puppeteer-core + шрифт Roboto
node server.mjs &                       # игра + мок SDK + шрифты на 127.0.0.1:8095
CHROME=/path/to/chrome VW=1152 VH=648 node direct.mjs      # кадры → work/frames/<сегмент>/ (~15 мин)
python3 audio.py                        # звук → work/audio.wav
python3 compose.py ../promo-ru.mp4      # монтаж и кодирование
```

- Сценарий, камера, подписи, стартовые сохранения — `direct.mjs` (отдельный сегмент: `node direct.mjs s3`).
- Таймлайн (такты 128 BPM, переходы) — `timeline.py`; музыка и сведение — `audio.py`.
- Курсор, подписи и финальная карточка — оверлей в `inject.js`. Для английской версии нужно перевести
  подписи в `direct.mjs` и `inject.js` и открыть игру с `lang: "en"` (`openGame` в `lib.mjs`).
- Раскладка 1152×648 CSS px масштабируется до 1920×1080 (компактная сцена, крупная машина).
  Приближения камеры снимаются clip-скриншотом с масштабом: игра заново растеризуется, поэтому
  картинка остаётся чёткой без апскейла.
