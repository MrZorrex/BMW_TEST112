# Как запустить игру на своём ПК

## Вариант 1 — просто играть (без установки чего-либо)

Скачай **`bmw-clicker-pc.zip`** из постоянного релиза
<https://github.com/MrZorrex/BMW_TEST112/releases/download/latest-build/bmw-clicker-pc.zip>
и распакуй — внутри один файл `index.html` (~2 МБ).

1. Открой его **двойным кликом** в любом современном браузере (Chrome, Edge, Firefox).
2. Всё — сервер, интернет и Node.js **не нужны**.

> В репозитории этого файла нет: `pc-build/index.html` — артефакт сборки (как и
> `dist/`, `publish/`), он генерируется командой ниже. Не путайте его с
> `index.html` в корне репозитория: тот файл — **исходник** точки входа Vite,
> в нём подключён SDK Яндекс Игр, руками его перезаписывать собранным файлом нельзя.

Прогресс сохраняется автоматически в браузере (localStorage), так что не открывай
каждый раз новую копию файла из загрузок — играй из одного и того же места.

Язык (русский/английский) переключается иконкой глобуса в шапке игры, на ПК
кликать можно Пробелом. Игра подстраивается под портретную и альбомную ориентацию.

## Вариант 2 — разработка / изменение кода

```bash
npm ci          # один раз: установка зависимостей
npm run dev     # запуск для разработки → http://localhost:5173
```

## Как пересобрать файл для ПК после изменений в коде

```bash
npm run build:pc
```

Готовый файл снова появится в `pc-build/index.html`.

> Сборка для Яндекс Игр — `npm run build:yandex` (сборка + проверка пакета +
> смоук-тест SDK + упаковка в `publish/bmw-clicker-yandex.zip`). Она по-прежнему
> включает SDK платформы, а ПК-версия собирается отдельно без него и потому
> работает полностью офлайн.
